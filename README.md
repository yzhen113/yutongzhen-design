# yutongzhen.design

Personal portfolio site for Yutong Zhen — rebuilt from Framer in Next.js.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Switzer (via Fontshare / Framer font assets)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Recommended: Vercel. Point `yutongzhen.design` DNS at the Vercel project when ready.
